# Tests for analyzer failure tracking

## Layout

- `analyzer/faildemo.spicy`, `analyzer/faildemo.evt`: a small Spicy protocol
  analyzer over UDP port 43107 whose first byte selects one of three
  malformed shapes. `faildemo.hlto` is generated by the acceptance script and
  is not committed (see `.gitignore`).
- `tools/make_trace.py`: dependency-free generator for the malformed UDP
  pcaps under `traces/`.
- `tools/replay_failures.py`: replays persisted `.bin` samples through the
  analyzer and verifies that the same category and parser error recur.
- `traces/malformed-all.pcap`: one datagram per failure category
  (`TRUNCATED`, `FORMAT`, `CONSTRAINT`). The `malformed-kindN.pcap` files
  contain a single category each.
- `run_acceptance.sh`: end-to-end entry point.

## Running

The script needs `zeek`, `spicyz` and a C++ compiler on `PATH`. It compiles
the test analyzer when needed, runs Zeek over the malformed trace, checks the
classifications and counters, then replays every persisted sample:

```sh
./tests/run_acceptance.sh
```

A successful run ends with `ACCEPTANCE PASSED` and exits zero.
